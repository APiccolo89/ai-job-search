\vspace{6pt}
\small{Research software engineer with a PhD in Computational Geodynamics and ten years building simulation software in Python, Julia, and C. Writes Python libraries that automate simulation workflows end to end: setting up models, running campaigns on HPC clusters, and processing, storing, and visualising the output. Tests and documents the tools so other researchers can use them, and supports the people who do.}

\section{Skills}
\vspace{1pt}
\begin{itemize}

\item \textbf{Python \& Scientific Software}: Object-oriented Python (NumPy, SciPy, pandas, Matplotlib, h5py, Numba, FEniCSx); dataclass-based configuration, YAML input, pip-installable packaging (pyproject); Julia, C, MATLAB

\item \textbf{Simulation Workflows \& Data}: Automated pipelines for simulation campaigns, post-processing, and analysis; HPC clusters (SLURM, PBS); MPI-parallel FEM (FEniCSx/PETSc); TB-scale data processing; built public databases (20 TB condensed to 200 GB); HDF5; SQL (learning)

\item \textbf{Numerical Methods}: Finite element and finite difference methods; coupled thermo-mechanical models with non-linear material laws; reduced-order models and parameter optimisation; validation against benchmarks

\item \textbf{Software Quality}: Git, GitHub Actions (CI), pytest with Codecov coverage, regression tests, Sphinx documentation on GitHub Pages, reproducible environments (venv/conda)

\item \textbf{AI-Assisted Development}: Daily use of Claude Code as an agentic coding assistant for scientific software development, test writing, and debugging

\end{itemize}
