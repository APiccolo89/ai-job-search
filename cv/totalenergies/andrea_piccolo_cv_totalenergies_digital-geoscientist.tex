\section{Core Competencies}
\vspace{1pt}
\begin{itemize}

\item \textbf{Geoscience Domain Expertise}: Stratigraphy, petrology, structural geology and geochemistry (MSc/BSc training); crustal and basin-scale mechanics from a decade of computational geodynamics research

\item \textbf{Python, SQL \& Workflow Automation}: NumPy, SciPy, pandas, h5py, Numba, pytest, growing SQL skills — building automated pipelines that connect simulation, processing, and reporting stages of geoscientific workflows

\item \textbf{Large-Scale Data Engineering}: TB-scale dataset condensation and curation (30 TB to 300 GB public databases), 100+ TB simulation data processed, HPC cluster computing (SLURM, PBS)

\item \textbf{AI/ML for Technical Workflows}: Daily use of Claude Code as an agentic coding assistant for pipeline development and debugging, giving practical, hands-on exposure to applying AI/ML tooling to accelerate geoscience workflows

\item \textbf{Software Engineering \& Collaboration}: Git, GitHub Actions (CI/CD), regression testing, cross-institutional collaboration, communicating technical results to varied technical audiences

\end{itemize}
