\vspace{6pt}
\small{Computational scientist with a PhD in Computational Geodynamics and ten years developing numerical simulation software in Python, Julia, and C. Builds finite element and finite difference solvers for thermo-mechanical problems, validates them against benchmarks, tests them, and documents them so other people can use them. Writes Python for data analysis, post-processing, and visualisation every day; processed 100+ TB of simulation output on HPC clusters. Presents and explains technical work to scientific audiences.}

\begin{itemize}
